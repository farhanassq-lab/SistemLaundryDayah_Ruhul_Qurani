SILAS — Perbaikan menu navigasi HP

File dalam paket ini:
- index.html
- styles.css

Cara memasang:
1. Buat salinan cadangan index.html dan styles.css lama di folder D:\SILAS_Web.
2. Ekstrak dua file dari ZIP ini langsung ke folder D:\SILAS_Web.
3. Setujui Replace/Timpa untuk index.html dan styles.css.
4. Jangan mengganti app.js, supabase-config.js, atau folder assets.
5. Buka ulang aplikasi dan login. Jika masih memakai cache, lakukan hard refresh (Ctrl+F5) di laptop atau tutup-buka ulang tab di HP.

Navigasi HP terpisah dari sidebar dan memakai handler .nav-item/data-view yang sudah ada di app.js. Desktop tetap memakai sidebar.
