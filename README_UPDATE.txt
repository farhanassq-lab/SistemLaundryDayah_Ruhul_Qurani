SILAS - Pembaruan desain visual

Cara menerapkan ke project SILAS yang sudah ada:
1. Cadangkan folder project yang sekarang.
2. Ekstrak isi ZIP ini ke folder project SILAS yang sudah ada.
3. Izinkan index.html dan styles.css diganti dengan versi baru.
4. Folder assets berisi logo Dayah Ruhul Qur'ani, foto santri berkelompok, dan foto masjid saat senja.
5. PENTING: jangan ganti file supabase-config.js atau app.js milikmu. Dengan begitu konfigurasi Supabase yang sudah diisi dan fungsi aplikasi tetap dipertahankan.
6. Jalankan `npx serve .` dari terminal di folder project, lalu buka alamat lokal yang tampil.

Logo Laundry BUD_RQ masih placeholder. Setelah logo asli tersedia, simpan di assets/logo-laundry-bud-rq.png lalu ikuti instruksi di README.md pada project lengkap.
